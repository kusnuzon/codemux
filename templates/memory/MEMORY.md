# MEMORY

Memori lintas sesi. Dimuat otomatis setiap sesi lewat `instructions` di
`~/.config/opencode/opencode.jsonc`. Ditulis lewat tool `memory_save`.

Aturan:
- satu fakta = satu baris, path absolut, tanpa basa-basi;
- batas keras 24.000 byte (jika lewat, `memory_save` gagal) — pangkas entri usang;
- jangan pernah menyimpan token/kunci/rahasia di sini.
